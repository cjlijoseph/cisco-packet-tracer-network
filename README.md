# Computer Networking Lab Project

## Overview
This project demonstrates a small network topology designed and simulated using Cisco Packet Tracer.

## Network Components
- PCs and laptops
- Network hub
- Wireless router
- NAS server
- Cable modem
- Cloud network
- Web server

## Project Objectives
- Understand basic network topology and device connectivity.
- Explore wired and wireless network configurations.
- Understand the roles of network devices and servers.
- Simulate a basic client-server and internet connectivity scenario.

## Tools Used
- Cisco Packet Tracer
- Networking Fundamentals
- LAN and WLAN Concepts
- Client-Server Networking

## Project Files
Open the `.pkt` file using Cisco Packet Tracer to inspect the network simulation.

## Learning Outcome
Gained practical exposure to network design, networking devices, and basic network connectivity concepts.
